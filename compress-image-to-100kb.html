How to reduce an image to 100KB

  1. Open the compressor using the button above. The 100KB target will be selected automatically.
  2. Choose a JPG, PNG, or WebP image from your device.
  3. Wait for the compressor to adjust quality and, only if needed, dimensions.
  4. Check that the result is under 100KB and download it. Compare the image visually before uploading it anywhere.

What happens when you set a 100KB target?

The tool tests higher quality settings first. If quality alone cannot bring the file below 100KB, it progressively reduces the image dimensions while preserving the original aspect ratio. Check the preview and final dimensions before you submit the file.

Tips before you upload

For portraits and scanned documents, make sure text remains readable and faces remain clear. If the upload form accepts a larger file, choosing a higher target may preserve more detail.

The tool runs image processing in your browser. Selected images are not uploaded to an image-processing server by this compressor. Keep your original file, especially when compressing an important photo or document.

Frequently asked questions

Will every image fit under 100KB?

Most ordinary images can be reduced substantially, but the result depends on source dimensions, detail, and format. The tool reports whether the target was reached; if it was not, review the output instead of assuming it meets the limit.

Is the target size guaranteed?

The compressor checks the resulting file size and labels whether the target was reached. Some files may need substantial resizing. Always use the actual result shown by the tool, not just the requested target.

Can I choose another limit?

Yes. Try our pages for 50KB, 100KB, 200KB, and 500KB, or set a custom target in the compressor.
