How to Compress Images Without Installing Software

Image compression reduces the amount of data needed to store a picture. Smaller files can be easier to share and may help web pages load faster, although the best settings depend on the image and its purpose.

1. Start with the original image

Keep a copy of the original before experimenting. Repeatedly saving lossy files can reduce quality.

2. Choose a sensible quality level

For photographs, start around 70–80% quality and inspect the result. Lower values often produce smaller files but can introduce visible artifacts.

3. Resize oversized images

If an image is much wider than it will appear on a page, reducing its dimensions can save data. Choose a maximum width that suits its use.

4. Choose an output format

JPG is broadly compatible and useful for photos. WebP can offer smaller files and supports transparency. JPG does not preserve transparency.

5. Compare before downloading

Check output size and visual quality. Not every file becomes smaller because a source image may already be optimized.
